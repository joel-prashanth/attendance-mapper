Aurora Attendance Privacy Policy

Last updated: 13 August 2026

Purpose

Aurora Attendance has one purpose: to enable authorized faculty members to preview and submit attendance from a configured Google Spreadsheet to Aurora ERP.

Information Accessed

The extension may access:

  • The authenticated faculty identity available through the user's current Aurora ERP session.
  • Faculty timetable information.
  • Existing ERP attendance session information.
  • Official ERP student class rosters.
  • Student registration numbers.
  • Attendance information contained in the Google Spreadsheet explicitly configured by the faculty member.

Authentication

Aurora Attendance uses the user's existing authenticated Aurora ERP browser session when communicating directly with Aurora ERP.

The extension does not intentionally read, copy or persist the user's Aurora ERP authentication cookie.

How Information Is Used

Information is used only to:

  • identify the authenticated faculty member;
  • discover faculty classes;
  • retrieve official class rosters;
  • compare Google Sheet registration numbers with ERP registrations;
  • validate attendance;
  • calculate attendance counts;
  • preview attendance before submission;
  • submit attendance to Aurora ERP only after explicit user confirmation.

Local Processing

Attendance matching and validation occur inside the user's browser.

Aurora Attendance does not operate a developer-controlled backend for receiving or storing ERP authentication credentials, student rosters, attendance records or Google Spreadsheet contents.

Locally Stored Configuration

The extension may store the following configuration in Chrome extension local storage:

  • ERP faculty profile name;
  • Google Spreadsheet identifier;
  • verified class-to-sheet mappings;
  • privacy consent status.

Student attendance records and ERP authentication cookies are not intentionally persisted in extension local storage.

Data Sharing

User data is not sold.

User data is not used for advertising, marketing or behavioral profiling.

Data is communicated only with the services required to provide the extension's attendance functionality: the configured Google Spreadsheet and Aurora ERP.

Data Retention

Attendance and roster information fetched for preview or submission is held in the running extension page and is not intentionally persisted by the extension.

Saved configuration remains in Chrome local extension storage until the user resets the extension, clears extension storage or uninstalls the extension.

User Control

Users can select "Reset Extension" from the application to remove all configuration and privacy-consent information stored locally by Aurora Attendance.

Security

Communication with Aurora ERP and Google services uses HTTPS.

Contact

Privacy or support questions can be sent to the publisher using the support contact listed on the Chrome Web Store page.
